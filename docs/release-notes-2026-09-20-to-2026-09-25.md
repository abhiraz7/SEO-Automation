# Release notes: 20 to 25 September 2026

The headline: **AI SEO Connector 1.5.0 is out.** It's the WordPress plugin that lets the SEO tool read
your site's on-page SEO data and apply approved fixes. Sites that were on 1.2.2 go straight to 1.5.0
when they update, so this release includes everything from 1.3.0 and 1.4.0 too.

## What you need to do

- **Update the plugin.** WordPress shows the update within about 12 hours. To get it now, go to
  Plugins and click **Check for updates** on the AI SEO Connector row.
- **Nothing to reconfigure.** Your token, connection and settings are kept.
- **A one-time "Awaiting connection" is normal.** After updating from 1.2.2 the plugin shows
  "Awaiting connection" until the tool next contacts the site (for example when you click
  *Test connection*). Then it shows "Connected". Nothing is wrong.

## New

- **Live connection status.** The plugin's settings screen and its WordPress menu icon show whether the
  tool is actually connected: connected, awaiting, idle (no contact for over a week) or paused.
- **Doctor.** A built-in health check for the connection. It looks at PHP and WordPress versions, HTTPS,
  permalinks and your SEO plugin, then makes a real request to your own site to catch problems such as a
  firewall or security plugin blocking the tool.
- **Pause / Resume.** Cut off the tool's access with one click and turn it back on later.
- **RankMath support.** SEO fixes now work on sites running RankMath as well as Yoast.
- **AI suggestions for image alt text.** The tool can now suggest alt text for individual images, with the
  suggestion checked before you accept it.
- **Page caches are cleared after a fix.** After a change, the plugin clears the affected page in the
  common cache plugins (WP Rocket, LiteSpeed Cache, W3 Total Cache, WP Super Cache, WP Fastest Cache,
  SiteGround) so visitors see the fix, and tells you which caches it cleared. CDN caches such as
  Cloudflare are not cleared.
- **Clean removal.** Deleting the plugin now also removes its token, settings and activity log.

## Changed

- **A simpler settings screen.** The dark, animated dashboard is replaced by a plain WordPress-style page:
  status and site name at the top, then Connection, Permissions and Tools. It uses WordPress's own look,
  so it follows your admin styling.
- **Clearer errors.** When the tool asks for something that isn't allowed, it now gets the real reason
  rather than a generic failure.
- **Plugin name.** The plugin is now called **AI SEO Connector** (it was previously named VtechSEO Agent).
- **License.** The plugin is now Proprietary / All Rights Reserved instead of GPL-2.0+.

## Fixed

- **Changing a page title could remove embeds from the page.** Updating only a title (for example an H1
  fix) could strip iframes, scripts and Custom HTML blocks from the page body while still reporting
  success. Content that isn't part of the change is now saved back exactly as it was.
- **Scheduling a draft published it immediately.** It now schedules it for the date you set.
- **Noindex and nofollow on RankMath.** A value of "false" was being treated as on, which could
  accidentally hide a page from search. It is now read correctly.
- **SEO audit counts non-English text correctly.** Hindi and other non-Latin pages were being miscounted
  (length and word count). The audit score also now counts warnings, not just errors.
- **Admin menu icon and screen width** were corrected.

## Security and privacy

- **The tool can only read a short list of site settings.** It used to be able to read almost any setting
  that wasn't specifically blocked. It now has an allow-list of nine.
- **Tool permissions are now enforced everywhere.** Switching off Content or Media used to still leave
  some read access open through one route. That is closed.
- **Content access is limited to public post types.** Private and internal post types (such as store
  orders) are not reachable, and sensitive-looking custom fields are blocked.
- **Wrong-token attempts no longer flood your database or lock the tool out.** Failed attempts are
  counted and rate-limited without a write per request, and a correct token is no longer rejected because
  a scanner from the same address tripped the limit.
- **Removed** the "sitemap ping" tool, because Google and Bing have retired those endpoints.

## Things to know if you connect other tools to the plugin's API

Most people can skip this. These behaviors changed in 1.4.0:

- The settings reader returns only the allow-listed keys.
- Content tools work on public post types only, and some custom-field names are blocked.
- MCP resources follow the same permission switches as the tools.
- The sitemap ping tool is gone.
- Permission and invalid-input problems return a specific 400/403 error instead of a generic 500.
- `GET /mcp` now returns 405, and notifications no longer get a reply.
- The audit `score` now takes warnings into account.

## Known limitations

- The new settings screen has been checked for code errors but has not yet been reviewed in a browser
  on every WordPress admin color scheme.
- The cache clearing was tested against stand-ins for each cache plugin, not the real plugins.
- If a release causes a problem, the rollback steps are in
  `prompts/AI-SEO-Connector-Rollback-Runbook.md`.
